# ShadowFox Data Analyst Internship – Intermediate Level

## 📊 Customer & Sales Performance Analysis

This project was completed as part of the ShadowFox Data Analyst Internship – Intermediate Level.

## 🎯 Objective

The objective of this project is to analyze customer and sales data to identify revenue trends, customer behavior, product performance, regional performance, and business opportunities.

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Data Analysis
- Charts & Dashboard

## 📁 Dataset

The dataset contains 240 sales transactions and 60 unique customers.

Key fields include:

- Order ID
- Order Date
- Customer ID
- Customer Name
- Region
- Segment
- Product
- Category
- Quantity
- Unit Price
- Discount
- Sales
- Cost
- Profit

## 📈 Analysis Performed

- Overall sales and profit analysis
- Monthly sales trends
- Customer performance analysis
- Repeat vs one-time customers
- Product-wise performance
- Region-wise performance
- Customer segment analysis
- Profit margin analysis
- Dashboard creation

## 📊 Dashboard

The Excel workbook contains a dashboard showing key business metrics and sales trends.

## 💡 Business Insights

The analysis identifies:

- Top-performing products
- Highest-performing regions
- Most valuable customer segments
- Monthly sales trends
- Repeat customer behavior
- Overall profitability

## 🎯 Recommendations

- Focus marketing efforts on high-value customers.
- Strengthen customer retention strategies.
- Promote high-performing products.
- Monitor underperforming regions.
- Use monthly sales trends for inventory and sales planning.
